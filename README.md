I developed an Item Catalogue project using the MERN stack (MongoDB, Express, React, Node.js), specifically designed for a wedding decoration business. The application features a login page where users must sign up to access the homepage. I implemented separate access levels: users can view all blogs and make inquiries via WhatsApp, while admins have additional privileges to create, edit, and delete blogs, as well as view lists of all users and blogs.
